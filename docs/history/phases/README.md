# Specs, plans et propositions clos

Documents datés en lecture seule. Une spec décrit ce qu'il fallait construire,
un plan comment le construire, et une proposition un choix évalué. Ils ne sont
pas réécrits pour refléter l'état présent.

Les suffixes `-spec`, `-plan` et `-proposal` évitent les collisions entre les
noms hérités. Les contrats actuels vivent dans `docs/current/` et les README de
features.
