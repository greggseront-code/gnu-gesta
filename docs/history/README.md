# Historique documentaire

Ce dossier conserve les artefacts datés sans les placer dans le parcours de
lecture courant :

- `phases/` : spécifications, plans et propositions closes ;
- `reviews/` : constats post-implémentation ;
- `analyses/` : études préalables qui ne gouvernent plus un travail actif.

Consulter l'historique uniquement pour retracer une décision, analyser une
régression ou répondre à une question historique. Une contrainte encore active
doit être formulée dans `docs/current/`, `docs/operations/` ou un README proche
du code ; un document historique ne doit jamais être sa seule source.

Les suffixes `-spec`, `-plan` et `-proposal` distinguent les anciens documents
qui portaient parfois le même nom. Certains artefacts décrivent leurs chemins
d'origine ; leur valeur de preuve reste inchangée et `docs/README.md` décrit la
structure actuelle.
