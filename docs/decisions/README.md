# Décisions architecturales

Les décisions durables qui contraignent plusieurs features prennent la forme
`ADR-NNNN-sujet.md` : statut, date, décision, raisons et conséquences.

Aucune ADR séparée n'est requise à ce jour : les invariants transversaux sont
encore couverts sans ambiguïté par `docs/current/architecture.md` et les README
de features. Ne pas créer une ADR pour une règle locale ou pour recopier ces
documents.
