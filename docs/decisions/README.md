# Décisions architecturales

Les décisions durables qui contraignent plusieurs features prennent la forme
`ADR-NNNN-sujet.md` : statut, date, décision, raisons et conséquences.

Les invariants transversaux restent couverts par `docs/current/architecture.md`
et les README de features. Ne pas créer une ADR pour une règle locale ou pour
recopier ces documents.

| ADR | Sujet |
| --- | --- |
| `ADR-0001-regles-de-livraison-et-de-cloture.md` | Raisons des règles de livraison et de clôture d'`AGENTS.md` |
